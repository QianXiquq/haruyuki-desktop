## Transitive dependencies

The table above covers direct dependencies only. Each package in `node_modules`

## A note on identifiers inherited from upstream

Two identifiers appear in the source because they are protocol and package
identifiers, not branding:

- the protocol field name `letta_code_version`
- the npm package `@letta-ai/letta-client` (a build-time dependency)

Renaming either would break compatibility with the wire protocol. No branding
assets — logos, wordmarks, images or ASCII art — from haruyuki or letta are
redistributed in this repository.
